为什么“整数步”能限制任意三维周期晶格？

三维晶格由三根独立的原胞基矢 a、b、c 反复平移生成。若旋转是晶格的对称性，每根旋转后的基矢就必须是 a、b、c 的整数倍组合。因此，旋转在原胞基底下的矩阵 A = B⁻¹RB 必为整数矩阵，它的迹（对角项之和）也是整数。

换一组坐标不会改变迹。三维正旋转沿轴方向贡献 1，垂直平面的旋转贡献 2cosθ，所以 tr A = tr R = 1 + 2cos(360°/n)。迹只能取 −1、0、1、2、3，对应 n = 2、3、4、6、1。五重的迹约为 1.618；所有 n ≥ 7 的迹都严格位于 2 和 3 之间，均不可能是整数。

这里的两个点阵提供具体示例；一般结论来自三维矩阵条件。终态检验使用无限晶格的坐标与基矢，不依赖显示窗口的边缘。

LECTURE 05 · BUILD A CRYSTAL

同样的格点，不同的结构。

晶格提供重复的规则，基元提供每个重复位置的内容。观察堆垛、孔隙和占位如何组织成晶体。

从几何模型到真实材料

课件中的离子半径、价态、配位统计提醒我们：硬球堆积与电中性只是结构分析的起点。真实结构还取决于键合、电子结构、温度、压力与占位有序。近似密堆积的阴离子骨架可以发生畸变；同样的化学式也可能有不同多型。

“非中心对称”只说明没有反演，镜面等不正操作仍可能存在。纤锌矿的 6mm 就是非中心对称、极性而非手性的例子；交换阳离子与阴离子的位置是构造另一种结构，不是同一结构里可以随意交换物种的对称操作。课件的 WOBr₄ 例子则说明：非手性的局部单元可以组成手性整体。
