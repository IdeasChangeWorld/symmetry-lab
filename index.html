为什么“整数步”能限制任意三维周期晶格？

三维晶格由三根独立的原胞基矢 a、b、c 反复平移生成。若旋转是晶格的对称性，每根旋转后的基矢就必须是 a、b、c 的整数倍组合。因此，旋转在原胞基底下的矩阵 A = B⁻¹RB 必为整数矩阵，它的迹（对角项之和）也是整数。

换一组坐标不会改变迹。三维正旋转沿轴方向贡献 1，垂直平面的旋转贡献 2cosθ，所以 tr A = tr R = 1 + 2cos(360°/n)。迹只能取 −1、0、1、2、3，对应 n = 2、3、4、6、1。五重的迹约为 1.618；所有 n ≥ 7 的迹都严格位于 2 和 3 之间，均不可能是整数。

这里的两个点阵提供具体示例；一般结论来自三维矩阵条件。终态检验使用无限晶格的坐标与基矢，不依赖显示窗口的边缘。

群的四个条件

01

封闭性组合任意两个操作，结果仍属于这个群。

02

结合律(A B) C = A (B C)，改变括号不改变结果。

03

恒等操作E A = A E = A，什么也不改变。

04

逆操作每个操作都有能撤销它的操作，A⁻¹ A = E。
